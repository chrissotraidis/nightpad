# NightPad 0.2.1

NightPad 0.2.1 fixes how the iPad's game window behaves with an external
display or TV, and on iPadOS 27 scene changes.

## Get it

This release contains a PadMint recipe and its checksum. There is no IPA, disc
image or game data to download. Build your personal IPA with PadMint as for
0.2.0 ([Get NightPad](https://github.com/chrissotraidis/nightpad#get-nightpad))
and install it over your existing NightPad with the same signing setup, so your
game data, saves and settings stay.

## What's in 0.2.1

- The iPhone and iPad device build now gets the same SDL 3.4.18 UIKit
  scene-geometry correction as KartPad and GalaxyPad (#8). Before, only the
  simulator build was patched. With it, NightPad runs only in its own app scene,
  leaves an external display or TV to iPadOS (mirroring or an extended display),
  adopts a replacement scene if iPadOS discards the first, and takes its
  orientation from the scene, which iPadOS 27 needs.
- Touch controls are unchanged. Controls › Touch Controls already has Auto-hide
  with Controller, Always Show and Always Hide.

## Tested

- PadMint's iOS route built the personal IPA from the Xbox disc image with the
  patch applied on the device lane. The linked SDL library and the app contain
  the scene-geometry functions. The package, privacy and patch checks pass.
- The behaviour was checked in the shared SDL harness on the iPadOS 27
  simulator: orientation follows the scene, a second app scene doesn't start the
  game again, and an external-display session gets no SDL delegate.
- PadMint's player check (Apple Python 3.9, empty PadMint folder, fresh clone)
  ran before tagging.

Not checked yet: a physical TV or external display, and play on the iPad with
this build. That acceptance is pending.
