# NightPad 0.2.0

The first public preview of NightPad: the original Xbox 007: Nightfire as a
native iPhone and iPad app, built on your own Mac with PadMint from your own
disc.

## Get it

This release contains a PadMint recipe and its checksum. There is no IPA, disc
image or game data to download. Follow
[Get NightPad](https://github.com/chrissotraidis/nightpad#get-nightpad): PadMint
builds your personal IPA and a NightPad game data folder from your Xbox disc
image, and you import that folder in the app.

## What's in 0.2.0

- Launch fixed for iPadOS 27, with a native-resolution borderless game window
  and render resolution up to 4× (2560×1920).
- Audio survives engine handoffs and restarts, and is held while the ⋯ menu is
  open.
- New codenames start on the game's Nightfire control scheme, and RB (Black)
  switches weapons.
- Touch layout editor rebuilt: grouped A/B/X/Y, Black/White and Start/Back,
  a Size slider and one opacity for the overlay. Sticks centre where your
  thumb lands and keep the finger that started on them.
- Cheats menu: Immortality, Unlimited Ammo, All Weapons and Unlock All Content.
- Blue app icon, themed launcher, About screen with repository and issue links.
- Start is held until a stopped session has finished shutting down.

## Tested

Played on an iPad Pro 12.9-inch (6th generation, iPadOS 27.0.1) with touch and
an Xbox controller: display, render resolution, controls and level audio are
confirmed. The quick suite, the 13-gate engine suite and a PadMint player check
(Apple Python 3.9, empty PadMint folder, fresh clone) pass.

Still open: a complete campaign with earned saves, iPhone hardware, four real
controllers, long sessions at 3× and 4×, and a device check of the post-editor
display fix, All Weapons, Unlock All and RB weapon switching. See
[Known issues](https://github.com/chrissotraidis/nightpad#known-issues).
