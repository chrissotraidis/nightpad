# NightPad branding

`nightpad-icon-source.jpg` is the original NightPad app icon artwork: a blue
full moon behind a silver scope ring, a streak of blue-white "night fire" and a
small Eiffel Tower, echoing the cold moonlit palette of the original box art.
`nightpad-launcher-source.jpg` is the matching wide home-screen backdrop.
Both were generated for this project and contain no game assets, likenesses,
logos or trademarks.

The iOS/iPadOS AppIcon in `apple/ios/Assets.xcassets` is a 1024 × 1024 opaque
256-colour PNG made from the icon source; Xcode generates every home-screen,
Settings and Spotlight size from it. `LauncherBackdrop` is a JPEG of the
backdrop. Tracked files stay under the 1 MB review limit in `scripts/check_privacy.sh`.
