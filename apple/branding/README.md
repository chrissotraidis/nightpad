# NightPad branding

`nightpad-icon-source.png` is the original NightPad app icon artwork: a blue
full moon behind a silver scope ring, a streak of blue-white "night fire" and a
small Eiffel Tower, echoing the cold moonlit palette of the original box art.
It was generated for this project and contains no game assets, likenesses,
logos or trademarks.

The iOS/iPadOS AppIcon in `apple/ios/Assets.xcassets` is a 1024 × 1024 opaque
derivative made with `sips -z 1024 1024`. Xcode generates every home-screen,
Settings and Spotlight size from that single image.

`nightpad-icon-alt-gold.png` is an earlier gold-and-crimson concept. It is kept
for comparison and is not used by the app.
